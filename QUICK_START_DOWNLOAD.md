## When Do I Need Cookies?

### Only if...
1. 🔞 Video is age-restricted (18+)
2. ⏳ You hit rate limit (HTTP 429 after many downloads)
3. 🌍 Video is geo-blocked to your region
4. 📊 You're downloading 100+ videos per day

### If none of above apply...
**You don't need cookies!** 🎉

---

## If You Get an Error

### Option 1: Try Again
Most errors are temporary. Click Download again.

### Option 2: Wait 30 Minutes
If you get "429 - Too Many Requests", wait and retry.

### Option 3: Add Cookies (Only If Needed)
```
1. Install Chrome extension (Get cookies.txt)
2. Log into YouTube/Instagram
3. Click extension → Export cookies.txt
4. Upload file in Downloader Settings
5. Try again
```

Takes ~2 minutes, but usually not necessary.

### Option 4: Try Different Video
If a specific video won't download, try another to test.

---

## Error Messages Explained

```
"Video not found"
→ Try checking the URL is correct

"HTTP 429 - Too Many Requests"
→ Downloaded too many videos recently
→ Solution: Wait 30 minutes OR add cookies

"Age-restricted content"
→ Video is 18+ only
→ Solution: Add cookies from your YouTube account

"Video is private"
→ Can't download private videos (impossible)
→ Solution: Ask video owner to make public/unlisted

"Slow or timeout"
→ Internet connection issue
→ Solution: Check connection, retry
```
